# Creative-media relay

Identify the idea's origin, reference roles, rights status, intended output, fixed identity/scene features and allowed variation. Keep private reference imagery and conversation history in private deployment storage, not inside a distributable skill.

Use a supported image tool for actual generation/editing when requested. Give every returned file an explicit candidate ID and record parent/prompt/tool/source provenance. Generation does not select a candidate; a crop, upscale, repair or overlay creates a new derived file.

Inspect the actual output at useful resolution. Check measured dimensions, MIME and bytes; do not call it 4K merely because the prompt requested 4K. Check likeness, anatomy, composition, background people and text as relevant. A still cannot establish video motion or audio quality. Unknown remains unknown.

Return the actual media through a capable attachment route. A path in a text-only message is not an attachment. Accept NEED_ATTACHMENT, REVISE, REJECT, HOLD or QUIET; enthusiastic prose is not explicit candidate selection.

Stage a bundle containing the selected image(s), exact caption and exact alt text. Require explicit file/candidate IDs and ordered file hashes. Recheck private exact-path mappings before upload. Approval of one component does not approve substituted bytes, changed order, a new caption or an unreviewed crop. Return material changes for author judgment.

Keep selection/endorsement, human action authority and execution outcome separate. No generation or staging step posts to a social account. The operator still verifies exact actor, target, reply parent, audience and bundle under the current action policy, then returns the actual result or uncertainty.
